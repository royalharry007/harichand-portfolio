# Harichand Chauhan — Developer Portfolio

A responsive, dark-themed personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

Update the following in `src/main.jsx`:
- Add your LinkedIn profile URL in `profile.links.linkedin`.
- Add a public resume PDF as `public/Harichand-Chauhan-Resume.pdf` (or change the resume link).
- Confirm all project metrics and technical claims match your implementation.
- Add real project screenshots in `public/` and update the project image paths if desired.

## Deploy

Import this folder into Vercel, or push it to GitHub and connect the repository to Vercel. Use the default Vite build settings:
- Build command: `npm run build`
- Output directory: `dist`
